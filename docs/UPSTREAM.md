AI Hub는 Herdr 데스크톱 앱의 소스를 가져와 이름과 배포 구성을 조정한 독립 프로젝트입니다.

## 보존 원칙

기준 커밋의 앱·터미널·작업 공간·탭·분할 화면·에이전트 관리·SSH 연결·모드 구현을 가져옵니다.
원본 기준 커밋을 기록하고 AI-HUB의 기존 커밋 이력을 이어서 출처와 이전 작업을 유지합니다.
원본의 전체 변경 이력은 위 원본 저장소에서 확인할 수 있습니다.
`LICENSE`, `THIRD-PARTY-NOTICES`, `licenses/`, vendored 의존성 및 `.gitmodules`를 유지합니다.
`vendor/ghostty`는 원본과 동일한 커밋을 가리키는 Git 하위 모듈입니다.

소스를 내려받아 빌드할 때는 하위 모듈도 받아야 합니다.

```sh
git clone --recurse-submodules https://github.com/q1926313-art/AI-HUB.git
```

`hc` 실행 엔진과 통신 프로토콜, `herdr` JavaScript 모듈 이름, 내부 `herdr-app` 명령과
공유 문서 키는 기존 모드 및 원격 연결의 호환성을 위해 유지합니다.
명칭이 코드 안에 남아 있는 부분은 호환성 식별자 또는 원본 출처 표시일 수 있습니다.

## 초기 수정 범위

- 창·메뉴·설정·설치 안내 등 사용자에게 보이는 앱 이름을 **AI Hub**로 변경합니다.
- Windows 설치 위치와 시작 메뉴 바로가기를 AI Hub용으로 구분합니다.
- 기본 앱 설정은 `~/.config/ai-hub`를 사용합니다. `AI_HUB_HOME`으로 변경할 수 있으며,
  기존 격리 실행을 위한 `HERDR_APP_HOME`이 명시되어 있으면 그 값을 우선합니다.
- 앱 업데이트는 이 저장소의 GitHub Releases를 사용합니다. `herdr-core` 설치·업데이트는
  해당 실행 엔진의 공식 배포 주소를 계속 사용합니다.
- 사용 통계는 별도 전송 주소를 명시하지 않으면 원본 프로젝트로 보내지 않습니다.
- 오류 보고는 AI-HUB 저장소로 연결하며, 원본 프로젝트의 수집 서버를 기본값으로 사용하지 않습니다.
- 원본 프로젝트 전용 서명·배포 비밀값에 의존하지 않는 Windows 빌드 및 릴리스 흐름을 둡니다.

자동 업데이트용 앱 패키지는 내부 `herdr-app` 폴더와 실행 파일 이름을 유지합니다.
배포 파일 이름과 사용자에게 보이는 설치 이름은 AI Hub입니다.

## AI Hub에서 추가한 기능

`0.1.17-aihub.2`는 `defaults/mods/team/`에 **AI 팀** 모드를 추가합니다.
계획·구현·검토·검증의 담당 에이전트와 지침을 설정하고, 로컬 프로젝트에서 역할을 순차 실행하며
구조화된 보고서를 다음 역할에 전달합니다. 사이드바와 명령 팔레트에서 열 수 있습니다.
기존 모드용 저장소, 파일 API 및 `hc` 명령을 사용하며 새로운 코어 프로토콜은 추가하지 않습니다.

모델과 실행 흐름의 회귀 검사, Linux 네이티브 모드 검사와 진단 산출물을 CI에 추가합니다.
사용법과 데이터 위치는 [AI 팀 안내](TEAM.md)에 기록합니다.

## 검증 범위

파일 보존 검사는 원본 커밋과 현재 트리의 경로·파일 내용·하위 모듈 커밋을 비교합니다.
수정한 설치 스크립트, 업데이트 주소 분리, 명령행 동작 및 원본 테스트를 대상으로 확인합니다.
Windows CI의 빌드·명령행 검사는 실제 Windows 데스크톱에서의 한글 입력·화면 렌더링
검사와 구분합니다. 실행하지 않은 검사는 통과한 것으로 기록하지 않습니다.

이 문서는 원본 전체 기능이 실제 실행 환경에서 검증되었다는 의미가 아닙니다.
현재 빌드 상태는 저장소의 Actions에서, 배포 파일은 Releases에서 확인할 수 있습니다.
